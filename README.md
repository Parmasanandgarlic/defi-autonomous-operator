# DeFi Autonomous Operator — Agent Skill

A generalized DeFi operating methodology implemented and validated against the
**FarmDash** runtime. It teaches an AI agent how to operate a bounded,
zero-custody DeFi control plane without confusing intelligence, policy,
delegation, preparation, signing, submission, or settlement.

This repository is the **standalone home** of the skill. It is not a FarmDash
product repository and does not contain FarmDash source.

## Security model

**Zero custody. Bounded authority. Local signing. Fail-closed runtime gating.**

```text
research → decision → policy → simulation → authority → preparation
         → local signing → submission → receipt → reconciliation
```

A later stage is never inferred from an earlier one:

| Payment | Session | Tool visible | Simulation | Prepared | Signature | Tx hash |
|---|---|---|---|---|---|---|
| ≠ authority | ≠ authority | ≠ authority | ≠ authority | ≠ signed | ≠ submitted | ≠ settlement |

The skill never requests, receives, stores, echoes, transforms, or transmits a
private key, seed phrase, or mnemonic.

### Execution modes

The two modes have **different authorization requirements**, and the skill
states them distinctly:

| Mode | Delegation required | Authorization for this action |
|---|---|---|
| `USER_SIGNED` | **No** | Fresh user approval/signature for this specific action |
| `BOUNDED_AUTONOMOUS` | **Yes** | A valid owner-signed, scoped, revocable grant covering this action |

A working session is not a grant. The agent cannot promote a session to
autonomy, and an autonomous grant cannot be assumed for a user-signed action.

## Validation

Run from this directory:

```bash
node validation/tools/validate-skill-truth.mjs     # 46 assertions
node validation/tools/test-skill-invariants.mjs    # security invariants
```

The drift validator reads canonical FarmDash truth **live** when a checkout of
`hububstudio/farmdashbeta` is present, and falls back to the vendored snapshot
in `reference/` when it is not. Either way the same assertions run.

Regenerate the snapshot from canonical source:

```bash
node validation/tools/extract-canonical-truth.mjs --json
```
