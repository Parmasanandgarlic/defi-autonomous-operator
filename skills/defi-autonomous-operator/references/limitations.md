# Limitations

- This skill governs *how an agent operates* a DeFi control plane. It does not
  implement execution, and it cannot create authority the runtime does not
  grant.
- It is a methodology, not a market strategy. It does not recommend assets,
  allocate capital, or predict price.
- It cannot prove settlement. It can only require the right reconciliation and
  refuse to overstate what the evidence shows.
- Capability readiness is a runtime property and changes. The
  `references/capability-matrix.md` table is orientation, not a live contract.
- It cannot repair a conflicting or broken runtime. When two canonical
  representations disagree, it surfaces the conflict rather than choosing.
- It performs no custody. Any deployment that gives the model key material has
  already violated the boundary this skill assumes.
- It contains no trading signals and makes no performance claim. Risk limits
  are admission controls, not guaranteed outcomes.
